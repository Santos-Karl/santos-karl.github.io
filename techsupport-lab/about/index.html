About this site

TechSupport Lab is a site for entry-level IT support work: troubleshooting, help desk tickets, Active Directory tasks, and hardware basics.

What is in the lab

  • Guides

    Step-by-step troubleshooting guides with commands, expected output, and verification steps.

  • Tickets

    Tickets from customers. Each one has questions, steps, and a model solution.

  • Queue

    Work incoming tickets: chat with the customer, get clues, and close with a resolution note.

  • Calls

    Phone calls with customers. Choose how to respond and get feedback on each choice.

  • Build

    Drag each part into place on a motherboard, then lock it. Wrong moves are explained.

  • Directory

    Search users, unlock accounts, and reset or disable access.

  • Scripts

    PowerShell scripts with copy buttons. The site never runs them. Read-only and changing scripts are labeled.

  • Downloads

    Checklists, a command reference, a worksheet, and a CSV template.

How to use it

  • Progress and changes are saved in your browser only. Nothing is linked to a real account.
  • Changing scripts need a lab you own, or written approval.
