PC build

Drag each part from the tray onto its slot, then secure it to lock it in place. Wrong moves explain why.

Follow your motherboard manual, and never open a power supply unit.

Step 1 of 13

Drag a part from the tray onto the highlighted slot. Keyboard and touch users can select a tray part and press Place.

Ground yourself and unplug the PC

Wear an anti-static wrist strap clipped to bare metal, or touch the unpainted case before each part. Keep the PC unplugged.

Build order

  1. Ground yourself and unplug the PC
  2. Open the CPU socket lever
  3. Place the CPU in the socket
  4. Mount the CPU cooler
  5. Install RAM stick 1 in slot A2
  6. Install RAM stick 2 in slot B2
  7. Install the M.2 SSD
  8. Mount the motherboard in the case
  9. Install the graphics card
  10. Mount the power supply
  11. Connect the 24-pin ATX cable
  12. Connect the CPU 8-pin power cable
  13. Connect the front panel cables
