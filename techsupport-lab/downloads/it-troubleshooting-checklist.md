# IT Troubleshooting Checklist

Use this checklist before escalating any ticket. Write down each step you took and its result.

## 1. Understand the problem
- [ ] Who is affected? One person, one team, or everyone?
- [ ] When did it start? What changed just before it?
- [ ] What is the exact error message or code? Take a photo or copy the text.
- [ ] Can the problem be repeated? What are the steps?

## 2. Check the basics
- [ ] Is the device powered on and plugged in?
- [ ] Is the network cable or Wi-Fi connected?
- [ ] Has the device been restarted?
- [ ] Does another device show the same problem?

## 3. Narrow it down
- [ ] Which layer fails: power, hardware, network, DNS, account, or application?
- [ ] Does the problem happen with a different user account?
- [ ] Does it happen in Safe Mode or with a clean profile?

## 4. Make one change at a time
- [ ] Write down the setting or file before you change it.
- [ ] Change one thing, then test.
- [ ] Undo the change if it does not help.

## 5. Verify the fix
- [ ] Repeat the original steps and confirm the problem is gone.
- [ ] Check the user can work normally.

## 6. Document and close
- [ ] Record the cause, the fix, and the steps taken.
- [ ] Tell the user what changed and what to do if it returns.
- [ ] Escalate if the fix needs approval, more access, or hardware replacement.

## Escalate when
- Data loss, a possible security incident, or a suspicious sign-in
- Hardware failure that needs a part replacement
- A change that needs approval (accounts, policies, firewall rules)
