Diagnose RAM problems

Symptoms of bad or incompatible memory, and a safe order of tests to find the faulty stick.

Overview

Bad RAM often shows up as random crashes, blue screens with memory-related codes, or a PC that will not boot. Test one stick at a time so you can identify the bad module.

Symptoms

  • Random restarts or blue screens, sometimes with memory-related stop codes.
  • The PC fails to start, or the motherboard gives a beep pattern.
  • Task Manager or BIOS shows less memory than installed.

Possible causes

  • A faulty module.
  • A module not fully seated, or in the wrong slot.
  • Mixed or unsupported speeds.

Step-by-step instructions

  1. Power off, unplug, and reseat each module until it clicks in place.
  2. Boot with one stick only, in the slot named in the manual. Note whether the PC is stable.
  3. Swap to the other stick and repeat. The stick that causes failures is the suspect.
  4. Run Windows Memory Diagnostic (mdsched.exe) on the suspect stick, then restart.
  5. Check the RAM speed and voltage in BIOS match the module rating (XMP or DOCP profile, if used).

Troubleshooting notes

  • Memory Diagnostic needs a restart and can take a while. Save open work first.

Common mistakes

  • Changing several things at once, so you cannot tell what fixed it.
  • Assuming every blue screen is RAM without checking the stop code.

Security and safety warnings

  • Unplug the PC before touching memory.
  • Use an anti-static strap, or touch the case first.

Verification steps

  • The PC runs stable under normal use for a few hours, and Memory Diagnostic reports no errors.

Commands

wmic memorychip get Capacity,Speed,Manufacturer

Lists installed memory modules with size and speed. Read-only.

Example output (typical, will vary)

Capacity     Manufacturer  Speed
8589934592   Example       3200
