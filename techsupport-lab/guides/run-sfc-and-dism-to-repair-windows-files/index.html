Run SFC and DISM to repair Windows system files

When Windows features or updates fail because system files are damaged, use DISM to repair the component store first, then SFC to repair system files.

Overview

SFC (System File Checker) compares protected system files with a cached copy. If the cache itself is damaged, SFC cannot repair files. DISM repairs the component store, so run DISM first, then SFC.

Symptoms

  • Windows features, Store apps, or updates fail with unclear error codes.
  • System files are reported as corrupt in logs.
  • Repeated crashes in system components.

Possible causes

  • Interrupted updates or disk errors.
  • Malware or failed third-party cleanup tools.
  • Damaged component store (WinSxS).

Requirements

  • An administrator account (Command Prompt must be opened as administrator).
  • A working internet connection, or a Windows source image if offline.
  • Back up important files first if the disk shows errors.

Step-by-step instructions

  1. Open Command Prompt as administrator.
  2. Run DISM /Online /Cleanup-Image /CheckHealth for a quick check. It reports whether damage is flagged.
  3. Run DISM /Online /Cleanup-Image /RestoreHealth to repair the component store. This can take a long time and needs internet access.
  4. Run sfc /scannow to repair system files from the repaired store.
  5. Restart the PC, then check logs in the CBS log file if SFC still reports problems.

Troubleshooting notes

  • SFC output 'Windows Resource Protection found corrupt files but was unable to fix some of them' means the component store still needs repair.

Common mistakes

  • Running sfc /scannow before DISM, then assuming SFC failed when the cache was damaged.
  • Interrupting DISM because it looks stuck. It can take 15 to 30 minutes on a slow PC.

Security and safety warnings

  • These commands change system files. Create a restore point or backup before running them on a machine that matters.
  • Do not run these on a company PC without approval from the administrator.

Verification steps

  • sfc /scannow reports no integrity violations or reports that repairs were made.
  • The original failing feature or update now works after a restart.

Commands

DISM /Online /Cleanup-Image /RestoreHealth

Downloads clean copies of damaged component store files from Windows Update.

Example output (typical, will vary)

The restore operation completed successfully.
The operation completed successfully.
sfc /scannow

Scans protected system files and replaces damaged ones from the component store.

Example output (typical, will vary)

Windows Resource Protection found corrupt files and successfully repaired them.
findstr /c:"[SR]" %windir%\Logs\CBS\CBS.log > sfc-details.txt

Extracts the SFC repair entries from the CBS log into a text file for review.

Example output (typical, will vary)

(No output when successful; check sfc-details.txt.)
