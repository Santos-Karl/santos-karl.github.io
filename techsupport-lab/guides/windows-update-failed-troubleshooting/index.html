Troubleshoot a Windows Update that keeps failing

Clear the update cache, run the built-in troubleshooter, and check the error code before trying repairs.

Overview

Updates fail for a few common reasons: a damaged update cache, a full system drive, or a driver conflict. Write down the error code first, then work from the simplest fix.

Symptoms

  • Updates stop at a set percentage or show an error code.
  • The same update keeps reappearing after a restart.

Possible causes

  • Damaged update cache.
  • Not enough free space on the system drive.
  • A driver or security product that blocks the update.

Requirements

  • Administrator rights for the repair steps.
  • At least 20 GB free on the system drive is a safe target.

Step-by-step instructions

  1. Note the exact error code in Settings > Windows Update > Update history.
  2. Run Settings > System > Troubleshoot > Other troubleshooters > Windows Update.
  3. Restart the PC and try the update again.
  4. If it still fails, stop the update services and clear the cache folder (see the commands), then start the services again.
  5. Run DISM and SFC if the error points to damaged system files.

Troubleshooting notes

  • Renaming the SoftwareDistribution folder (instead of deleting it) keeps a copy if something goes wrong.

Common mistakes

  • Stopping the service and forgetting to start it again.
  • Deleting cache files while another update is still running.

Security and safety warnings

  • These steps change system files. Create a restore point first on a machine that matters.
  • Do not turn off security products without approval.

Verification steps

  • The update installs and Settings shows Up to date.
  • No new error appears after a restart.

Commands

net stop wuauserv

Stops the Windows Update service so the cache can be cleared. Needs administrator rights.

Example output (typical, will vary)

The Windows Update service was stopped successfully.
net start wuauserv

Starts the Windows Update service again after the cache is cleared.

Example output (typical, will vary)

The Windows Update service was started successfully.
