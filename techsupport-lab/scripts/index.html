PowerShell Scripts

Copy a script, read it, and run it in your own lab or with approval. This site never runs scripts.

Read-only scripts only read information. Scripts marked "changes system" modify accounts or settings. Use them only in a lab or with approval.

8 scripts

  • Systemread-only

    Get basic computer information

    Shows the computer name, Windows version, processor, memory, and time since the last restart.

  • Systemread-only

    Check free disk space

    Lists each drive with its size and free space, so you can spot a full disk quickly.

  • Systemread-only

    List installed applications

    Lists installed programs from the Windows uninstall registry keys, sorted by name.

  • Networkread-only

    Check network configuration

    Shows each network adapter with its IP address, default gateway, and DNS servers.

  • Networkread-only

    Test connectivity to the gateway and the internet

    Pings the default gateway, a public IP address, and a name lookup to find which layer fails.

  • Logsread-only

    List recent error events

    Shows critical and error events from the System log in the last 24 hours.

  • Userschanges systemadmin

    Unlock an Active Directory account (lab only)

    Clears the lockout on a lab account after you have verified who asked for it.

  • Userschanges systemadmin

    Disable an Active Directory account (lab only)

    Disables a lab account when access must be removed. The account is kept, not deleted.
