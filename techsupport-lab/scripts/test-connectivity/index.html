Test connectivity to the gateway and the internet

Pings the default gateway, a public IP address, and a name lookup to find which layer fails.

Requirements

  • Windows 10 or Windows 11
  • A default gateway set on the adapter

Permissions required

Standard user is enough.

Script

$gateway = (Get-NetRoute -DestinationPrefix "0.0.0.0/0" | Select-Object -First 1).NextHop
"Gateway ($gateway):   " + (Test-Connection -ComputerName $gateway -Count 2 -Quiet)
"Public IP (8.8.8.8): " + (Test-Connection -ComputerName 8.8.8.8 -Count 2 -Quiet)
"DNS name lookup:     " + [bool](Resolve-DnsName -Name "www.microsoft.com" -ErrorAction SilentlyContinue)

How the important commands work

  • Each test checks one layer. The first False tells you where to look next.
  • -Quiet returns True or False instead of a long report.

Example output

Typical output. Your result will differ.

Gateway (192.168.1.1):   True
Public IP (8.8.8.8): True
DNS name lookup:     True

How to run it

  1. Run in PowerShell. Read the three results from top to bottom.

Risks and limitations

  • Some networks block ping, so False does not always mean the internet is down. Check with a web request too.

Verification

  • All three show True when a web page loads normally.
