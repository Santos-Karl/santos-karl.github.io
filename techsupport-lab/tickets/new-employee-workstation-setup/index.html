INC-0007

A new employee needs a workstation

Priority
High
Impact
New hire cannot start work on their first day.
Customer
Hannah Brooks
Department
Human Resources

Ticket description

We have a new hire starting Monday. They need a laptop with email, the shared drive, and the standard software.

Contact: hannah.brooks@example.com

Questions to ask

  1. What is the start date, and who is the manager?
  2. Which role or department, and which software is required?
  3. Does the employee need a new account or a copy of an existing role?

Troubleshooting steps

  1. Create the account in the directory with the approved naming standard and a temporary password that must be changed at first sign-in.
  2. Add the account to the groups for its role.
  3. Build the laptop from the standard image, join it to the domain, and install the approved software.
  4. Test sign-in, email, the shared drive, and each required application before handover.
Show model solution

Expected findings

  • The account, groups, and laptop are ready, and the user can sign in and open the shared drive.

Resolution

  • Hand the laptop over with a checklist and the first sign-in instructions, and send the temporary credentials through the approved channel.

Documentation notes

Account name, groups added, device asset tag, software installed, and the signed checklist.

Escalation criteria

Escalate if a required application needs a license or manager approval that is not yet in place.

Sample ticket closure

Your laptop and account are ready. Sign in with the temporary password we sent through the approved channel, then choose a new one. Email and the shared drive have been tested. Contact us if any application is missing.
